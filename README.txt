Pooja Acharya - Portfolio
=========================

How to open
  1. Unzip this folder.
  2. Double-click index.html. It opens in any modern browser (Chrome, Edge, Firefox, Safari).

What is inside
  index.html                  The portfolio page
  Pooja_Acharya_Resume.pdf    The file behind the Download Resume buttons
  assets/photo.jpg            Your photo

Notes
  - The 3D background (Three.js) and the fonts load from the internet.
    Offline, the page still works and shows the same content without the 3D scene.
  - To change the resume, replace Pooja_Acharya_Resume.pdf and keep the same file name.
  - To host it online, upload the whole folder to GitHub Pages, Netlify or Vercel.
